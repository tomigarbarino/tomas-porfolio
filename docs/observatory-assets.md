# Observatory asset provenance

All media is self-hosted. Existing portfolio assets were reused for this implementation; source screenshots and research archives are not shipped.

| Asset | Source and use |
| --- | --- |
| `public/media/hero-ascii.*` | ASCII derivative of the existing public Batech demo. Cinematic environment and matching still poster. |
| `public/media/batech-product.*` | Original public Batech company demo and poster from the preceding portfolio. Company context, with frontend contribution stated separately. |
| `public/media/minecraft-ascii.*` | Animated thematic reference derived from the [official exploration screenshot](https://www.minecraft.net/en-us/article/exploring-minecraft). Not a personal game capture. |
| `public/media/cafe-ascii.*` | Animated thematic reference derived from [Haberdoedas's café photo](https://unsplash.com/photos/cafe-entrance-with-outdoor-seating-and-menu-board-52L-6wBJIj4). Source provenance recorded under the Unsplash License during design research. Not a client café. |
| `public/media/trainly-product.png`, `public/media/trainly/` | Public Trainly demo, brand and concept material from the preceding portfolio. Captions distinguish product interfaces from conceptual graphics. |
| `public/media/agora-*.png`, `agora-logo.svg` | Owner-supplied [Agora design file](https://www.figma.com/design/gKp8MoVlJ2vdftqeyqmyht/Agora---Design-file). Only empty candidate preparation designs and brand are used. No real CVs, candidate names, interview transcripts or results are included. |
| `public/media/stickers/` | Original generated developer-sticker artwork prepared for this portfolio. |
| `public/cursors/tg-pink.svg`, leader SVGs, `icon.svg` | Original portfolio interface graphics. |
| `public/fonts/` | Unmodified Barlow Condensed Black and IBM Plex Mono Regular from Google Fonts. Their SIL Open Font License texts are included beside the font files. |

Watch Dogs 2 informed the art direction, timing and layered navigation. Game footage, characters, logos and game fonts are not included.
