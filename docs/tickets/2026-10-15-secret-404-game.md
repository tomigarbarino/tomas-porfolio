## Implementation

1. Add `src/app/not-found.tsx` for the server-rendered error message and return link. Keep `/404` deliberately unmatched so the root fallback serves the same genuine 404 as other missing URLs. An explicit page calling `notFound()` was removed after the built HTTP test found it lacked the useful server shell.
2. Add a route-specific client loader and `PacketRecoveryGame` plus scoped CSS. Eight native whole-tile controls reveal four pairs. No timer, lives or automatic mismatch timeout. Randomize on first user action and reset so server/client output remains deterministic.
3. Keep the game implementation out of the ordinary portfolio route payload where practical; it loads on the 404 view. No video downloads or new packages.
4. Reveal `curiosity.txt` after four matches; move focus to its heading. Replay returns focus to the board. Provide polite text announcements, visible focus, >=44 px targets, normal Tab/Enter/Space operation and optional board-scoped number/arrow shortcuts.
5. Add a discreet accessible footer link to `/404`, without changing the primary navigation or project storytelling.

- Lint, typecheck and production build. Browser checks at desktop, 390 px and 320 px: complete/mismatch/replay, keyboard focus and announcements, outside-board shortcut behavior, reduced motion/global pause, overflow and return navigation.
- HTTP 404 + noindex on `/404`, a top-level unknown path and a nested unknown path. Home/Agora/Trainly remain 200 and their discovery contracts pass.

## Risks / exclusions / rollback

No API, data, database, tracking, account or dependency changes. Do not alter existing project animations or drag contracts. Avoid exposing sealed pair identities in accessible names. Do not use `role=application` or document-global game shortcuts. A mismatch remains until the next valid selection, preserving enough reading time.

Rollback: revert this feature commit; there is no migration or persistent game state. Done means the public 404 and footer entry serve the playable design, not only a Figma prototype.
