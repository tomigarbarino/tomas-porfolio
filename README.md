## 🚀 Getting Started

### Prerequisites

- Node.js >= 18.0.0
- npm >= 9.0.0

### Installation

```bash
# Clone repository
git clone https://github.com/yourusername/portfolio.git

# Install dependencies
npm install

# Start development server
npm run dev
```

### Available Scripts

```bash
npm run dev          # Start development server
npm run build        # Build for production
npm run type-check   # Check TypeScript types
npm test             # Run tests
```

## 🏗️ Architecture

### Folder Structure

```
src/
├── components/          # React components
│   ├── navbar/
│   ├── footer/
│   ├── contact_section/
│   └── ...
├── pages/              # Page components
├── lib/                # Utilities and helpers
│   ├── utils/          # Utility functions
│   └── hooks/          # Custom hooks
└── types/              # TypeScript type definitions
```

### Key Decisions

**TypeScript Migration**: Gradual migration from JavaScript to TypeScript for type safety and better maintainability.

**React Query**: Implemented for efficient server state management, eliminating manual loading/error state management.

**Component Separation**: Clear separation between presentational and container components.
